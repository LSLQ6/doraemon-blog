写文章

写完点发布，文章会自动同步到你的 GitHub 仓库，几分钟后博客上就能看到。

发布需要一个有仓库写权限的 token，只在本页面使用，关闭页面即清除。获取方法见下方说明。

如何获取访问令牌（只需做一次）
  1. 打开 GitHub → 右上角头像 → Settings
  2. 左下角 Developer settings → Personal access tokens → Fine-grained tokens
  3. 点击 Generate new token，Repository access 选 Only select repositories，勾选 doraemon-blog
  4. Permissions 里找到 Contents，设为 Read and write，然后生成
  5. 把生成的 token 复制，粘贴到本页上方的输入框即可
